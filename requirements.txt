# Core ML stack
torch>=2.2.0
# Pinned to an EXACT version, not just a "<5.0.0" range: on Colab, a range
# constraint was not enough -- `pip install --upgrade -r requirements.txt`
# still resolved to transformers 5.16.1, which has a tokenizer-loading
# regression for TrOCR/RoBERTa-style tokenizers ("need sentencepiece or
# tiktoken to convert a slow tokenizer to a fast one" -- not actually a
# missing-package issue, TrOCR's tokenizer never needed sentencepiece;
# it's a bug in that release line). 4.46.3 is a stable release with
# TrainingArguments' `eval_strategy` argument name (src/train.py), which
# older 4.x releases only accept as the deprecated `evaluation_strategy`.
# If you need a newer transformers for an unrelated reason, confirm TrOCR
# tokenizer loading still works before bumping this.
transformers==4.46.3
accelerate>=0.30.0,<1.0.0
sentencepiece>=0.1.99   # some tokenizers need this; harmless to keep either way
protobuf>=3.20.0        # sentencepiece's serialization dependency

# Metrics -- note: this is jiwer directly (src/metrics.py), not HuggingFace's
# `datasets`/`evaluate` libraries. Neither of those is imported anywhere in
# this repo (src/train.py builds its own PyTorch Dataset, src/metrics.py
# computes CER/WER via jiwer directly) -- they were dropped from this file
# because they pulled in a version conflict (`datasets` wants an older
# `fsspec` than a reconciled huggingface_hub/gradio pulls in) for zero
# functional benefit. Add `datasets` back only if you actually use
# `datasets.Dataset` / `evaluate.load(...)` somewhere.
jiwer>=3.0.3

# Deployment demo
# Upper bound matters here, not just style: Colab pre-installs a recent
# gradio (6.26.0 observed) built against a newer huggingface_hub major
# version than the one transformers==4.46.3 above requires
# (huggingface_hub<2.0,>=1.x vs <1.0). Left unbounded, `gradio>=4.31.0`
# alone is still "satisfied" by that pre-installed 6.26.0, so plain pip
# would leave it in place and it would conflict with huggingface_hub
# post-install; <6.20 forces pip to actually reconcile it down to a
# version (verified: 6.17.3) built against the older huggingface_hub line.
gradio>=4.31.0,<6.20
