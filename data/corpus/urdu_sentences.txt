# Curated Urdu sentence corpus
#
# One genuine, grammatically correct Urdu sentence/phrase per line.
# Lines starting with # are comments and are ignored by the loader.
#
# This corpus feeds `src/synthetic.py`, which renders every line in several
# fonts / sizes / backgrounds / noise levels to build a large, varied
# synthetic training set (see docs/ACCURACY_NOTES.md). It also doubles as
# real ground truth if you print these lines and photograph them.
#
# Topics covered on purpose (per the Week 1 / Week 3 "variety" requirement):
# greetings, news/headline style, proverbs, signage/short phrases,
# book/paragraph style, numbers & dates.
